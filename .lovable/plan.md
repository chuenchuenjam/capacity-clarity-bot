# Professional AI Showcase Redesign

## Direction
Apply the selected **Neural interface** design across the existing product: bright editorial surfaces, crisp dark typography, indigo AI accents, rich media previews, and restrained depth. Preserve the current knowledge tree, editing, demos, assistant, decks, permissions, and file workflows.

## What will change

1. **Create a cohesive visual system**
   - Refresh semantic colors, typography, borders, shadows, focus states, and spacing.
   - Use a polished light workspace with a focused dark navigation rail and indigo AI accents.
   - Add subtle transitions and loading feedback while respecting reduced-motion settings.

2. **Modernize the workspace shell**
   - Refine the desktop navigation for clearer hierarchy and less visual noise.
   - Add a compact mobile header and slide-over navigation so the product works cleanly on phones.
   - Turn Ask Assistant into a persistent, high-visibility command bar rather than a small utility button.

3. **Make the homepage presentation-ready**
   - Strengthen the opening area with a confident Knowledge Center title and prominent AI query field.
   - Present product demos as rich, cinematic tiles with clear play, tag, description, and product-link actions.
   - Restyle recent knowledge into concise media rows with document status and update details.
   - Give useful empty states the same polished treatment without inventing demo content.

4. **Elevate the AI experience**
   - Redesign the assistant panel with a clear welcome state, suggested questions, polished answer hierarchy, source-friendly formatting, and prominent deck creation.
   - Improve thinking, disabled, success, and failure states so demonstrations feel deliberate and reliable.

5. **Refine documents and generated decks**
   - Improve document reading width, breadcrumbs, status display, editing controls, attachments, and embedded media presentation.
   - Restyle generated decks as a presentation stage with clearer navigation, notes, export, and save actions.
   - Keep admin and editor controls discoverable without competing with the content.

6. **Polish entry screens and verify quality**
   - Bring sign-in and password recovery into the same visual language.
   - Verify the homepage, navigation, assistant, documents, demo playback, and deck viewer on desktop and mobile.
   - Confirm keyboard focus, contrast, text fit, empty states, and reduced-motion behavior.

## Technical details
- Extend the existing semantic design tokens rather than adding hardcoded page colors.
- Reuse the current buttons, dialogs, sheets, inputs, and permissions logic.
- Keep all backend behavior and stored content unchanged.
- Use the selected prototype as the structural and visual reference, adapted to the existing desktop workspace rather than copied as a separate mobile-only screen.
